\begin{frame}{What is LaTeX?}
    \begin{itemize}
        \item LaTeX is a document preparation system.
        \item It is widely used for technical and scientific writing.
        \item It supports mathematical equations, tables and figures.
    \end{itemize}
\end{frame}

\begin{frame}{Important Features of LaTeX}
    \begin{itemize}
        \item Structured writing using sections and chapters.
        \item Professional formatting of equations and tables.
        \item Automatic numbering and references.
        \item Beamer can create slide presentations.
    \end{itemize}
\end{frame}

\begin{frame}{Conclusion}
    \begin{itemize}
        \item LaTeX creates well-structured documents.
        \item It is useful for reports and research papers.
        \item Beamer makes professional presentations.
    \end{itemize}
